# Fragloot
## Description
FragLoot is a server-side Teeworlds mod that adds a new gametype based on Deathmatch.

The main difference is how score works. When you kill another player, you dont get the score immediately. Instead, a score pickup is dropped at the place where the player died.

You have to pick it up to get the score.

If another player picks it up, they steal the point and get an extra point as a bonus.

The mod also comes with 3 new maps specifically for this mode, namely:
* Fragloot1
* Fragloot2
* Fragloot3
